# Claude Architect Certification — Exam Prep Outline

A five-section study plan covering the core domains of the Claude Architect certification.

## 1. Claude Fundamentals and Model Selection

- Overview of the Claude model family and capability tiers
- Choosing a model based on latency, cost, context window, and task complexity
- Tokenization, context limits, and output constraints
- API basics: messages, system prompts, stop sequences, and temperature
- Pricing, rate limits, and quota management

## 2. Prompt Engineering and Context Management

- System prompt design and role definition
- Clear instructions, examples, and output formatting
- Few-shot and multi-shot prompting patterns
- Chain-of-thought and structured reasoning techniques
- Managing long conversations and context-window budgets
- Prompt caching and reducing redundant tokens

## 3. Tool Use, Agents, and MCP

- Tool definitions, schemas, and tool-choice strategies
- Designing reliable tool-use loops and handling tool errors
- Multi-step agent architectures and orchestration patterns
- Retrieval-augmented generation (RAG) integration
- Model Context Protocol (MCP): servers, clients, and transports
- Security boundaries and least-privilege tool access

## 4. Application Architecture and Integration

- Reference architectures for Claude-powered applications
- Streaming responses and asynchronous processing
- State management, session handling, and persistence
- Multi-agent and workflow decomposition patterns
- Error handling, retries, and graceful degradation
- Cost, latency, and scalability trade-offs

## 5. Safety, Evaluation, and Operations

- Responsible AI principles and Anthropic usage policies
- Prompt injection, jailbreak, and data-exfiltration defenses
- Input/output validation and content moderation
- Evaluation strategies: benchmarks, human review, and regression tests
- Observability: logging, tracing, and monitoring model behavior
- Deployment, versioning, and continuous improvement practices
